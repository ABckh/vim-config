# Neovim config

Based on [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim). This branch uses Neovim 0.12 or newer and the built-in plugin manager. See the [upstream installation guide](https://github.com/nvim-lua/kickstart.nvim#installation) for system dependencies.

Use a native `tree-sitter` CLI (0.26.1 or newer) on your `PATH` for parser installation.

Mason installs language servers for Python, TypeScript, Bash, JSON, and Lua. Install LazyGit on your `PATH` to use `<Space>gg`. Use `<Space><Space>` to find files and `<Space>/` for live grep.
